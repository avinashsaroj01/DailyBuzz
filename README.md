# DailyBuzz

DailyBuzz is a news aggregation application that fetches and displays the latest news from various sources. It aims to provide users with a seamless and intuitive experience to stay updated with current events.

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/avinashsaroj01/DailyBuzz.git
    cd DailyBuzz
    ```

2. Install dependencies:
    ```sh
    npm install
    ```

3. Create a `.env` file in the root directory and add your environment variables:
    ```env
    NEWS_API_KEY=your_news_api_key
    ```

4. Start the development server:
    ```sh
    npm start
    ```

## Features

- Fetches news from various sources using an API
- Displays news articles in a user-friendly interface
- Search functionality to find specific news articles
- Categories to filter news by topic

## Usage

1. Start the development server as described above.
2. Open your browser and navigate to `http://localhost:3000`.
